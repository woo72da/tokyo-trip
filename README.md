# 도쿄 여행 PWA

아이폰 홈 화면에 추가해서 쓰는 오프라인 여행일정 앱입니다. 서버나 빌드 과정이 필요 없는 정적 파일입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `data/trip.json` | 일정·항공·숙소·체크리스트·가이드 데이터 (**일정 수정은 여기서만**) |
| `index.html`, `styles.css`, `app.js` | 화면 (오늘 / 일정 / 정보 / 체크) |
| `sw.js` | 오프라인 캐시 (앱 파일 + 발음 파일) |
| `audio/`, `tools/make_audio.py` | 일본어 발음 녹음 파일과 만드는 스크립트 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설정 |

## 로컬에서 보기

```bash
python3 -m http.server 8765 --directory travel-app
```

`http://localhost:8765/?now=2026-11-05T15:30` 처럼 `now`를 붙이면 여행 중 특정 시각의 화면을 미리 볼 수 있습니다.

## 배포 (HTTPS 필요: 서비스 워커는 HTTPS에서만 동작)

- **GitHub Pages**: 저장소를 만들고 `travel-app` 폴더 안의 파일을 업로드한 뒤, Settings → Pages에서 브랜치를 지정합니다.
- **Netlify Drop**: app.netlify.com/drop 에 `travel-app` 폴더를 끌어다 놓습니다.

배포한 URL은 공개 주소입니다. 그래서 예약번호(항공 PNR, 아고다 예약번호), eSIM 설치 링크, 바우처·QR 사진은 `trip.json`에 넣지 않고, 앱의 예약 탭에서 각 기기에만 저장합니다 (번호는 localStorage, 사진은 IndexedDB).

## 예약정보 동기화

예약 탭 맨 위 '예약정보 동기화'를 펼치면 체크 상태·예약번호·eSIM 링크·지출·예산·내가 추가한 항목·문서 사진(추가한 문서 포함)을 담은 파일이 미리 준비됩니다. '보내기'를 누르고 공유 창에서 카카오톡이나 AirDrop을 고릅니다. 웹앱은 카카오톡에 파일을 직접 넣거나 받은 파일을 자동으로 읽을 수 없으므로, 받은 폰에서 파일을 '파일' 앱에 저장한 뒤 '받은 파일 합치기'를 누릅니다 (같은 항목은 나중에 바꾼 쪽이 이기고, 지운 기록은 되살아나지 않음). 동기화 파일에는 이 정보가 암호화 없이 들어 있으니 프로젝트 폴더에 두거나 GitHub에 올리지 않고, 보낸 뒤 대화방의 파일은 지웁니다. 서버를 쓰지 않으므로 사진과 번호는 두 폰과 주고받은 파일에만 있습니다.

## 일본어 발음 파일

아이폰은 무음 스위치가 켜져 있으면 브라우저 음성 합성을 막지만 오디오 파일은 재생합니다. 그래서 회화·장소 이름의 일본어 발음을 `audio/`에 녹음 파일(Kyoko 음성, 개인 여행용)로 넣어 둡니다. 회화나 장소를 바꾸면 Mac에서 다시 만듭니다.

```bash
python3 tools/make_audio.py
```

## 아이폰 설치

1. Safari로 URL을 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 홈 화면 아이콘으로 한 번 연 뒤 **비행기 모드에서 다시 열어** 오프라인 동작을 확인합니다.

## 일정을 고친 뒤

1. `data/trip.json`을 수정하고 다시 배포합니다.
2. 앱 화면 파일(html/css/js)을 고쳤다면 `sw.js`의 `VERSION`도 올립니다 (예: `trip-v2`).
3. 폰에서 인터넷에 연결된 상태로 앱을 한 번 열면 새 일정이 반영됩니다.

## 일정 알림

아이폰 웹앱은 닫혀 있을 때 서버 없이 알림을 보낼 수 없습니다. 그래서 놓치면 안 되는 일정(`alarm` 값이 있는 항목)을 `calendar.ics`로 만들어 오늘 탭의 '일정 알림 받기'에서 캘린더에 넣습니다. 아이폰 홈 화면 앱은 파일을 직접 열지 못해 Safari로 넘깁니다. 안드로이드 캘린더가 파일의 알림을 빼고 가져오면 같은 화면의 Google 캘린더 링크로 일정별로 추가합니다. 일정 시간을 바꾸면 `python3 tools/make_ics.py`를 다시 실행합니다.
