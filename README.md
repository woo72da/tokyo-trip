# 도쿄 여행 PWA

아이폰 홈 화면에 추가해서 쓰는 오프라인 여행일정 앱입니다. 서버나 빌드 과정이 필요 없는 정적 파일입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `data/trip.json` | 일정·항공·숙소·체크리스트·가이드 데이터 (**일정 수정은 여기서만**) |
| `index.html`, `styles.css`, `app.js` | 화면 (오늘 / 일정 / 정보 / 체크) |
| `sw.js` | 오프라인 캐시 (앱 파일 + 발음 파일) |
| `audio/`, `tools/make_audio.py` | 일본어 발음 녹음 파일과 만드는 스크립트 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설정 |

## 로컬에서 보기

```bash
python3 -m http.server 8765 --directory travel-app
```

`http://localhost:8765/?now=2026-11-05T15:30` 처럼 `now`를 붙이면 여행 중 특정 시각의 화면을 미리 볼 수 있습니다.

## 배포 (HTTPS 필요: 서비스 워커는 HTTPS에서만 동작)

- **GitHub Pages**: 저장소를 만들고 `travel-app` 폴더 안의 파일을 업로드한 뒤, Settings → Pages에서 브랜치를 지정합니다.
- **Netlify Drop**: app.netlify.com/drop 에 `travel-app` 폴더를 끌어다 놓습니다.

배포한 URL은 공개 주소입니다. 그래서 예약번호(항공 PNR, 아고다 예약번호), eSIM 설치 링크, 바우처·QR 사진은 `trip.json`에 넣지 않고, 앱의 예약 탭에서 각 기기에만 저장합니다 (번호는 localStorage, 사진은 IndexedDB).

## 예약정보 동기화

예약 탭 맨 위 '예약정보 동기화'를 펼치면 체크 상태·예약번호·eSIM 링크·지출·예산·내가 추가한 항목·바우처·자료(직접 추가한 항목 포함)을 담은 파일이 미리 준비됩니다. '보내기'를 누르고 공유 창에서 카카오톡이나 AirDrop을 고릅니다. 웹앱은 카카오톡에 파일을 직접 넣거나 받은 파일을 자동으로 읽을 수 없으므로, 받은 폰에서 파일을 '파일' 앱에 저장한 뒤 '받은 파일 합치기'를 누릅니다 (같은 항목은 나중에 바꾼 쪽이 이기고, 지운 기록은 되살아나지 않음). 동기화 파일에는 이 정보가 암호화 없이 들어 있으니 프로젝트 폴더에 두거나 GitHub에 올리지 않고, 보낸 뒤 대화방의 파일은 지웁니다. 서버를 쓰지 않으므로 사진과 번호는 두 폰과 주고받은 파일에만 있습니다.

## 일본어 발음 파일

아이폰은 무음 스위치가 켜져 있으면 브라우저 음성 합성을 막지만 오디오 파일은 재생합니다. 그래서 회화·장소 이름의 일본어 발음을 `audio/`에 녹음 파일(Kyoko 음성, 개인 여행용)로 넣어 둡니다. 회화나 장소를 바꾸면 Mac에서 다시 만듭니다.

```bash
python3 tools/make_audio.py
```

## 아이폰 설치

1. Safari로 URL을 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 홈 화면 아이콘으로 한 번 연 뒤 **비행기 모드에서 다시 열어** 오프라인 동작을 확인합니다.

## 일정을 고친 뒤

1. `data/trip.json`을 수정하고 다시 배포합니다.
2. 앱 화면 파일(html/css/js)을 고쳤다면 `sw.js`의 `VERSION`도 올립니다 (예: `trip-v2`).
3. 폰에서 인터넷에 연결된 상태로 앱을 한 번 열면 새 일정이 반영됩니다.

## 일정 알림

아이폰 웹앱은 닫혀 있을 때 서버 없이 알림을 보낼 수 없습니다. 그래서 놓치면 안 되는 일정(`alarm` 값이 있는 항목)을 `calendar.ics`로 만들어 일정 탭 맨 아래의 '일정 알림 받기'에서 캘린더에 넣습니다. 아이폰 홈 화면 앱은 파일을 직접 열지 못해 Safari로 넘깁니다. 안드로이드 캘린더가 파일의 알림을 빼고 가져오면 같은 화면의 Google 캘린더 링크로 일정별로 추가합니다. 일정 시간을 바꾸면 `python3 tools/make_ics.py`를 다시 실행합니다.

## 탐색

하단 탐색 탭은 `data/trip.json`의 `places` 목록을 먹고·마시고·보고·사고으로 보여 줍니다. 값은 구글지도를 보고 저장한 것이라 실시간이 아니며, 인터넷 없이도 열립니다. 저장, 방문, 메모, 사진은 폰에 저장되고 예약정보 동기화로 주고받습니다. 일정의 방문 완료 화면에서 쓴 돈, 재방문 평가(강력 추천·추천·비추천), 한 줄 메모를 남기면 경비와 방문 기록에 저장됩니다. 예약 탭 경비에서 직접 기록할 때는 날짜(출발 전 또는 1~5일차)를 고릅니다. `영수증 등록`을 누르면 기록한 뒤 바로 사진을 고르고, 지출을 눌러 영수증 사진을 더 넣거나 봅니다. 영수증 사진은 바우처처럼 폰(IndexedDB)에만 저장되고 동기화 파일에 함께 담깁니다. 지난 날의 일정 탭 맨 아래에는 도장, 완료·방문 수, 그날 지출, 평가와 메모를 모은 하루 요약이 나옵니다.

장소 썸네일은 `places[].photo`에 넣은 구글지도 사진 링크입니다. 이미지 파일은 저장소에 없고, 인터넷이 없거나 링크가 만료되면 카테고리 아이콘이 대신 보입니다.

앱에서 추가한 장소와 일정, 시간 변경, 건너뛰기는 `trip.json`을 바꾸지 않고 폰에 저장되며 동기화로 주고받습니다. 캘린더 알림은 자동으로 바뀌지 않습니다.

## 일정 편집과 지연

- 일정 탭의 `편집`을 누르면 일정을 눌러 고치고, 일정 사이 `＋ 여기에 일정 넣기`로 끼워 넣습니다. 맨 아래 `＋ 일정 추가`는 늘 보입니다.
- 일정 수정 화면에서 제목·종류·날짜·시간·장소(직접 추가한 일정만)·메모·시간 고정을 바꿉니다. 시작을 바꾸면 걸리는 시간에 맞춰 끝나는 시간이 따라오고, 새벽 시간이 되면 낮 시간으로 고치는 버튼이 나옵니다.
- 시간을 늦추면 뒤 일정이 함께 밀리는 미리보기가 나옵니다. 일정 사이 빈 시간이 먼저 지연을 흡수하고, `hard` 일정이나 `시간 고정`을 켠 일정은 움직이지 않습니다. 고정 일정과 겹치면 앞 일정을 줄이거나 겹친 채로 둡니다.
- 삭제는 숨기기라서 편집 모드의 `삭제한 일정`에서 되살립니다. `이날 시간을 원래 계획으로`는 그날 바꾼 시간만 되돌립니다.
- 오늘 탭은 시작 시간이 지났는데 끝나지 않은 일정을 모두 `밀린 일정`으로 순서대로 보여 주고, 맨 앞 일정부터 완료·건너뛰기를 받습니다. `지금부터 시작 · 뒤 일정 밀기`와 `15분 더`는 수정 화면을 미리 채워 엽니다.

## 폰트

본문은 Pretendard, 숫자는 IBM Plex Mono입니다. `fonts/`에 넣어 앱과 함께 오프라인 저장되며, Pretendard는 일반 한글 2,350자와 앱에 쓰인 글자만 담았습니다. 라이선스는 `fonts/OFL.txt`에 있습니다.

앱 아이콘 원본은 `tools/icon.svg`입니다. 인트로는 최초 실행, 앱 업데이트 후, 오늘 탭 로고를 누를 때 나오며 `index.html`에 있습니다.

여행 글에서 온 장소는 `places`의 `src`·`status`·`caution`으로 구분합니다. `verified`가 있는 곳만 구글지도로 위치를 확인한 곳이고, 좌표가 없으면 위치 미확인입니다. 상호를 모르는 항목은 `unresolved`에 둡니다.

## 날씨 총평과 아침 준비

- 날씨는 Open-Meteo에서 지난 2일과 앞으로 16일을 받아, 날짜별로 폰에 저장합니다(`wxlog`). 지난 날씨는 실제 관측이 아니라 기상 모델 값입니다.
- 일정 탭 하루 요약에는 그날 날씨를 한 줄로 정리한 총평(비 온 시간, 맑음·흐림, 기온, 자외선, 해 나온 시간)과 `챙긴 것 어땠나요?`(우산·선글라스·겉옷, 한 줄 메모)가 나옵니다. 기록은 이 폰의 사람 이름으로 저장되고 동기화로 주고받습니다(`gear:날짜:이름`).
- 오늘 탭은 그날 첫 일정 전까지(04시부터) `오늘 아침 준비` 카드를 보여 줍니다. 어제와 오늘 날씨를 비교하고, 시간대별 날씨와 밖에 있는 일정을 보고 챙길 것을 고르며, 가장 최근 기록에 따라 기준을 바꿉니다(우산을 안 썼으면 약한 비 확률에는 빼고, 선글라스가 아쉬웠으면 더 쉽게 추천하고, 추웠으면 겉옷을 한 단계 두껍게). `준비 완료`를 누르면 접힙니다.
