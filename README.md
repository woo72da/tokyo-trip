# 도쿄 여행 PWA

아이폰 홈 화면에 추가해서 쓰는 오프라인 여행일정 앱입니다. 서버나 빌드 과정이 필요 없는 정적 파일입니다.

## 구성

| 파일 | 역할 |
|---|---|
| `data/trip.json` | 일정·항공·숙소·체크리스트·가이드 데이터 (**일정 수정은 여기서만**) |
| `index.html`, `styles.css`, `app.js` | 화면 (오늘 / 일정 / 정보 / 체크) |
| `sw.js` | 오프라인 캐시 (앱 파일 + 발음 파일) |
| `audio/`, `tools/make_audio.py` | 일본어 발음 녹음 파일과 만드는 스크립트 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설정 |

## 로컬에서 보기

```bash
python3 -m http.server 8765 --directory travel-app
```

`http://localhost:8765/?now=2026-11-05T15:30` 처럼 `now`를 붙이면 여행 중 특정 시각의 화면을 미리 볼 수 있습니다.

## 배포 (HTTPS 필요: 서비스 워커는 HTTPS에서만 동작)

- **GitHub Pages**: 저장소를 만들고 `travel-app` 폴더 안의 파일을 업로드한 뒤, Settings → Pages에서 브랜치를 지정합니다.
- **Netlify Drop**: app.netlify.com/drop 에 `travel-app` 폴더를 끌어다 놓습니다.

배포한 URL은 공개 주소입니다. 그래서 예약번호(항공 PNR, 아고다 예약번호), eSIM 설치 링크, 바우처·QR 사진은 `trip.json`에 넣지 않고, 앱의 예약 탭에서 각 기기에만 저장합니다 (번호는 localStorage, 사진은 IndexedDB).

## 자동 배포 (바뀐 파일만)

이 폴더는 GitHub 저장소 `woo72da/tokyo-trip`과 연결되어 있습니다. 파일을 고친 뒤 터미널에서 아래를 실행하면 바뀐 파일만 골라 올리고, 사이트에 반영될 때까지 기다렸다가 알려 줍니다.

```bash
tools/deploy.sh
```

- 올리기 전에 바뀐 파일 목록을 보여 주고 `y`를 눌러야 올립니다. `-y`를 붙이면 묻지 않습니다.
- 화면 파일(`app.js`, `styles.css`, `index.html`, `sw.js`)이 바뀌었는데 `sw.js`·`app.js` 버전이 그대로면 멈춥니다. 두 버전이 다를 때도 멈춥니다.
- `data/trip.json`, `manifest.webmanifest`, `audio/index.json` 말고 다른 JSON 파일(동기화 파일 등)과 eSIM 링크로 보이는 내용은 올리지 않습니다. 동기화 파일 이름(`도쿄여행-*.json`)과 `.DS_Store`는 아예 목록에 넣지 않습니다.
- GitHub에만 있는 파일은 지우지 않습니다.
- 처음 한 번은 GitHub 로그인이 필요합니다: `brew install gh` → `gh auth login`(GitHub.com · HTTPS · 브라우저 로그인) → `gh auth setup-git`.

## 예약정보 동기화

예약 탭 맨 위 '예약정보 동기화'를 펼치면 체크 상태·예약번호·eSIM 링크·지출·예산·내가 추가한 항목·바우처·자료(직접 추가한 항목 포함)을 담은 파일이 미리 준비됩니다. '보내기'를 누르고 공유 창에서 카카오톡이나 AirDrop을 고릅니다. 웹앱은 카카오톡에 파일을 직접 넣거나 받은 파일을 자동으로 읽을 수 없으므로, 받은 폰에서 파일을 '파일' 앱에 저장한 뒤 '받은 파일 합치기'를 누릅니다 (같은 항목은 나중에 바꾼 쪽이 이기고, 지운 기록은 되살아나지 않음). 동기화 파일에는 이 정보가 암호화 없이 들어 있으니 프로젝트 폴더에 두거나 GitHub에 올리지 않고, 보낸 뒤 대화방의 파일은 지웁니다. 서버를 쓰지 않으므로 사진과 번호는 두 폰과 주고받은 파일에만 있습니다.

## 일본어 발음 파일

아이폰은 무음 스위치가 켜져 있으면 브라우저 음성 합성을 막지만 오디오 파일은 재생합니다. 그래서 회화·장소 이름의 일본어 발음을 `audio/`에 녹음 파일(Kyoko 음성, 개인 여행용)로 넣어 둡니다. 회화나 장소를 바꾸면 Mac에서 다시 만듭니다.

```bash
python3 tools/make_audio.py
```

## 아이폰 설치

1. Safari로 URL을 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 누릅니다.
3. 홈 화면 아이콘으로 한 번 연 뒤 **비행기 모드에서 다시 열어** 오프라인 동작을 확인합니다.

## 일정을 고친 뒤

1. `data/trip.json`을 수정하고 다시 배포합니다.
2. 앱 화면 파일(html/css/js)을 고쳤다면 `sw.js`의 `VERSION`도 올립니다 (예: `trip-v2`).
3. 폰에서 인터넷에 연결된 상태로 앱을 한 번 열면 새 일정이 반영됩니다.

## 일정 알림

아이폰 웹앱은 닫혀 있을 때 서버 없이 알림을 보낼 수 없습니다. 그래서 놓치면 안 되는 일정(`alarm` 값이 있는 항목)을 `calendar.ics`로 만들어 일정 탭 맨 아래의 '일정 알림 받기'에서 캘린더에 넣습니다. 아이폰 홈 화면 앱은 파일을 직접 열지 못해 Safari로 넘깁니다. 안드로이드 캘린더가 파일의 알림을 빼고 가져오면 같은 화면의 Google 캘린더 링크로 일정별로 추가합니다. 일정 시간을 바꾸면 `python3 tools/make_ics.py`를 다시 실행합니다.

## 탐색

하단 탐색 탭은 `data/trip.json`의 `places` 목록을 먹고·마시고·보고·사고으로 보여 줍니다. 값은 구글지도를 보고 저장한 것이라 실시간이 아니며, 인터넷 없이도 열립니다. 저장, 방문, 메모, 사진은 폰에 저장되고 예약정보 동기화로 주고받습니다. 일정의 방문 완료 화면에서 쓴 돈, 재방문 평가(강력 추천·추천·비추천), 한 줄 메모를 남기면 경비와 방문 기록에 저장됩니다. 예약 탭 경비에서 직접 기록할 때는 날짜(출발 전 또는 1~5일차)를 고릅니다. `영수증 등록`을 누르면 기록한 뒤 바로 사진을 고르고, 지출을 눌러 영수증 사진을 더 넣거나 봅니다. `카드 문자로 등록`에 카드 승인 문자(여러 건 가능)나 카드 앱 캡처에서 복사한 글자를 붙여 넣으면 금액·통화·날짜·시간·가게를 폰 안에서 읽어 확인 목록으로 보여 주고, 고른 것만 등록합니다. 같은 날 같은 금액이 이미 있으면 꺼 두며, 카드 번호와 이름은 저장하지 않습니다(삼성 해외승인·일반 국내 승인 형식 기준). 영수증 사진은 바우처처럼 폰(IndexedDB)에만 저장되고 동기화 파일에 함께 담깁니다. 지난 날의 일정 탭 맨 아래에는 도장, 완료·방문 수, 그날 지출, 평가와 메모를 모은 하루 요약이 나옵니다.

일정 정보의 `알고 가면 좋은 팁`(`info.know`)은 구글지도 문구를 옮긴 것이 아니라 직접 정리한 방문 요령이고, 최신 팁은 `구글지도에서 최신 팁 보기`로 엽니다.

장소 썸네일은 `places[].photo`에 넣은 구글지도 사진 링크입니다. 이미지 파일은 저장소에 없고, 인터넷이 없거나 링크가 만료되면 카테고리 아이콘이 대신 보입니다.

앱에서 추가한 장소와 일정, 시간 변경, 건너뛰기는 `trip.json`을 바꾸지 않고 폰에 저장되며 동기화로 주고받습니다. 캘린더 알림은 자동으로 바뀌지 않습니다.

## 일정 편집과 지연

- 일정 탭의 `편집`을 누르면 일정을 눌러 고치고, 일정 사이 `＋ 여기에 일정 넣기`로 끼워 넣습니다. 맨 아래 `＋ 일정 추가`는 늘 보입니다.
- 일정 수정 화면에서 제목·종류·날짜·시간·장소(직접 추가한 일정만)·메모·시간 고정을 바꿉니다. 시작을 바꾸면 걸리는 시간에 맞춰 끝나는 시간이 따라오고, 새벽 시간이 되면 낮 시간으로 고치는 버튼이 나옵니다.
- 시간을 늦추면 뒤 일정이 함께 밀리는 미리보기가 나옵니다. 일정 사이 빈 시간이 먼저 지연을 흡수하고, `hard` 일정이나 `시간 고정`을 켠 일정은 움직이지 않습니다. 고정 일정과 겹치면 앞 일정을 줄이거나 겹친 채로 둡니다.
- 삭제는 숨기기라서 편집 모드의 `삭제한 일정`에서 되살립니다. `이날 시간을 원래 계획으로`는 그날 바꾼 시간만 되돌립니다.
- 오늘 탭은 시작 시간이 지났는데 끝나지 않은 일정을 모두 `밀린 일정`으로 순서대로 보여 주고, 맨 앞 일정부터 완료·건너뛰기를 받습니다. `지금부터 시작 · 뒤 일정 밀기`와 `15분 더`는 수정 화면을 미리 채워 엽니다. 그날 모든 일정의 시작 시간이 지났는데 끝내지 않은 일정이 있으면 `오늘 일정을 마무리할까요?` 카드에서 한 번에 완료하거나 건너뛰고, 그러면 도장 카드가 나옵니다. 지나온 날과 도장을 찍은 날은 도장 아래 숫자와 일정 탭 날짜에 빨간 동그라미로 표시됩니다.

## AI 도우미 (구글지도 링크 → 장소)

- 예약 탭 `AI 도우미`에 본인 Claude API 키를 넣으면 켜집니다. 키는 그 폰의 localStorage(`aiKey`)에만 있고 동기화 파일과 GitHub에는 들어가지 않습니다. Claude 콘솔에서 월 사용 한도를 걸어 두는 것을 권합니다.
- `일정 추가`(또는 탐색 탭 `＋`)에서 구글지도 공유 내용을 붙여 넣고 `AI로 채우기`를 누르면, Claude가 링크와 웹 검색으로 장소를 확인해 이름·일본어 이름·분류·지역·좌표·영업시간·휴무·평점·추천·팁·머무는 시간을 앱의 장소 형식으로 채웁니다. 장소는 `내 장소`에 저장되고 일정 제목·종류·장소·소요 시간이 채워지며, 저장 전에 영업시간·겹침 경고와 뒤 일정 밀림을 그대로 확인합니다.
- 기본 모델은 Claude Opus 5.5(낮은 effort, 거절 시 서버 대체 모델 사용), 설정에서 Haiku 5.5로 바꿀 수 있습니다. 공식 SDK(`@anthropic-ai/sdk@1.1.0`)를 쓸 때만 esm.sh에서 불러옵니다.
- 구글 장소 키(Places API (New), `gKey`, 이 폰에만 저장)를 넣으면 장소 이름을 입력할 때 구글 추천 목록이 나오고, 고르면 구글 지도와 같은 위치·영업시간·휴무·평점·리뷰 수·사진·지도 링크를 가져옵니다. AI 키도 있으면 Claude가 한국어 이름·설명·추천·팁·머무는 시간을 덧붙입니다(웹 검색 없이 구글 정보만 보고 작성). 키는 웹사이트(woo72da.github.io)와 Places API (New)로 제한해 두세요. 구글 약관상 장소 ID 외 정보는 오래 보관하지 않는 것이 원칙이라, 이 정보는 폰에만 두고 저장소에는 넣지 않습니다.
- 키가 없거나 인터넷이 없으면 `링크로 채우기`가 공유 내용의 이름·주소·좌표만 채웁니다. AI가 채운 정보에는 `AI가 찾은 정보 · 확인 필요` 표시가 붙습니다.

## AI로 하는 일 (AI 키가 있을 때)

- **영수증 사진으로**(예약 탭 경비): 영수증을 찍으면 가게·날짜·시간·합계·결제수단·분류·품목을 읽어 확인 화면을 띄우고, 등록하면 사진도 그 지출의 영수증으로 저장합니다.
- **카드 앱 캡처 사진으로**(카드 문자로 → 사진 버튼): 캡처 화면의 결제를 모두 읽어 카드 문자와 같은 확인 목록으로 보여 줍니다.
- **메뉴판·안내문 사진 번역**(번역 탭): 메뉴·안내문·자판기 사진을 한국어로 옮기고 가격(엔·원)과 여기서 쓸 일본어 한 줄(발음 듣기)을 보여 줍니다.
- **말로 일정 바꾸기**(일정 탭): 원하는 변경을 적으면 바뀔 내용을 전/후로 보여 주고 `이대로 적용`을 눌러야 반영됩니다. 고정 일정 변경은 주황색으로 표시되고, 적용 후 `되돌리기`로 한 번에 되돌립니다.
- **AI에게 조정 방법 물어보기**(오늘 탭 밀린 일정 카드): 지금 시각과 고정 일정을 넣은 질문으로 조정안 2~3개를 받아 고릅니다.
- **오늘 기록 정리하기**(지난 날의 하루 요약): 방문·평가·메모·지출·날씨로 짧은 여행 일기를 쓰고 공유·복사할 수 있습니다(`diary:날짜`, 동기화 포함).
- 사진은 분석할 때만 Claude로 보내고, AI 결과는 늘 확인 화면을 거친 뒤 저장됩니다.

## 개선 요청 (💬)

- 예약 탭 AI 도우미에 `개선 요청함 토큰`(비공개 저장소 `woo72da/tokyo-trip-desk`에만 Contents·Issues 쓰기 권한)을 넣으면 화면 오른쪽 아래에 💬 버튼이 생깁니다.
- 내용과 캡처·영상(최대 6개, 영상 25MB 이하)을 보내면 요청함에 이슈로 쌓이고, 요청함의 GitHub Actions에서 Claude가 검토해 분명한 수정은 이 앱을 고쳐 배포하고, 큰 변경이나 모호한 요청은 질문을 남깁니다. 앱 버전·화면·시각·최근 오류가 함께 갑니다.
- `내 요청`에서 접수됨 → 처리 중 → 반영됨/확인 필요 상태와 Claude의 답을 보고, 답하거나 되돌리기를 요청합니다.
- 첨부와 요청 내용은 비공개 요청함에만 있고 이 공개 저장소에는 들어오지 않습니다.

## 폰트

본문은 Pretendard, 숫자는 IBM Plex Mono입니다. `fonts/`에 넣어 앱과 함께 오프라인 저장되며, Pretendard는 일반 한글 2,350자와 앱에 쓰인 글자만 담았습니다. 라이선스는 `fonts/OFL.txt`에 있습니다.

앱 아이콘 원본은 `tools/icon.svg`입니다. 인트로는 최초 실행, 앱 업데이트 후, 오늘 탭 로고를 누를 때 나오며 `index.html`에 있습니다.

여행 글에서 온 장소는 `places`의 `src`·`status`·`caution`으로 구분합니다. `verified`가 있는 곳만 구글지도로 위치를 확인한 곳이고, 좌표가 없으면 위치 미확인입니다. 상호를 모르는 항목은 `unresolved`에 둡니다.

## 날씨 총평과 아침 준비

- 날씨는 Open-Meteo에서 지난 2일과 앞으로 16일을 받아, 날짜별로 폰에 저장합니다(`wxlog`). 지난 날씨는 실제 관측이 아니라 기상 모델 값입니다.
- 일정 탭 하루 요약에는 그날 날씨를 한 줄로 정리한 총평(비 온 시간, 맑음·흐림, 기온, 자외선, 해 나온 시간)과 `챙긴 것 어땠나요?`(우산·선글라스·겉옷, 한 줄 메모)가 나옵니다. 기록은 이 폰의 사람 이름으로 저장되고 동기화로 주고받습니다(`gear:날짜:이름`).
- 오늘 탭은 그날 첫 일정 전까지(04시부터) `오늘 아침 준비` 카드를 보여 줍니다. 어제와 오늘 날씨를 비교하고, 시간대별 날씨와 밖에 있는 일정을 보고 챙길 것을 고르며, 가장 최근 기록에 따라 기준을 바꿉니다(우산을 안 썼으면 약한 비 확률에는 빼고, 선글라스가 아쉬웠으면 더 쉽게 추천하고, 추웠으면 겉옷을 한 단계 두껍게). 기록 때문에 실제로 바뀐 항목이 있을 때만 그 이유를 보여 줍니다. `준비 완료`를 누르거나 첫 일정 시작 시간이 되면 사라지고, 완료 직후 알림의 `다시 보기`로 되돌립니다.
- 아침 준비 카드는 이 폰 사람을 부르는 인사로 시작합니다(날마다 바뀜). 그날 동선, 시간이 정해진 일정, 날씨 한마디를 비서처럼 알려 줍니다. 연필 버튼으로 부르는 이름(별명)을 바꾸며, 이 폰에만 저장됩니다.
- 아침 준비 카드의 `브리핑 듣기`는 폰의 한국어 음성으로 인사·동선·날씨·챙길 것을 읽어 줍니다(시간은 '오후 1시 40분'처럼 읽음). 아이폰은 무음 모드에서 소리가 나지 않고, 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성에서 '유나(향상됨)'를 받아 두면 더 자연스럽습니다.
- 하늘은 아이폰 날씨처럼 구름 양으로 정합니다 (25% 미만 맑음, 50% 미만 대체로 맑음, 80% 미만 구름 많음, 그 이상 흐림). 날씨 카드에는 그날 비 양(mm)을, 시간별 칸에는 비 오는 시간의 mm를 함께 보여 줍니다.
- 18시부터 오늘 탭에 `내일` 카드가 나와 내일 날씨, 비 양(새벽·밤에 몰렸는지), 챙길 것을 보여 주고, 누르면 그날 일정으로 갑니다.
- 비 시간은 오늘 탭 날씨 카드와 아침 준비가 같은 기준(비 확률 50% 이상이거나 비 예보인 시간, 08~22시)으로 셉니다. 일정에 걸린 비 확률은 그 일정 시간의 값입니다.
