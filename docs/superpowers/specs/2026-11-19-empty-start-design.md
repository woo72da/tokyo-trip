# 여행 없는 처음 상태 (v310, 짧은 설계)

## 왜
여행이 하나도 없는 사람이 남의 도쿄 일정을 봐요. 내보내진 사람, 마지막 여행을 지운 사람, 처음 깐 폰이 여기에 해당해요. 이런 사람에게는 빈 화면과 시작 방법만 보여야 해요.

## 정한 것 (사용자)
- 로그인하지 않은 새 폰도 빈 처음 상태예요(A안). 도쿄 일정은 도쿄 여행에 연결된 폰에서만 보여요.
- 탭은 그대로 두고, 탭마다 빈 화면과 다음 할 일을 보여 줘요. 번역 탭은 그대로 써요.

## 방식
- `state.noTrip` 표시와 빈 일정 `emptyPlan()`(days 없음)을 둬요. 일본 회화, 회화 단계, 긴급 연락처만 도쿄 파일에서 가져와요.
- `render()`: noTrip이면 오늘, 일정, 탐색, 예약, 체크 탭은 `noTripView(tab)`을 그려요. 번역 탭은 원래대로예요.
- 탭 하나를 시작 화면으로 덮는 방식은 쓰지 않아요. 번역까지 막히기 때문이에요.

## 언제 처음 상태인가
- 시작할 때(`init`):
  - 연결된 여행(`cloudTrip`)이 있으면 지금처럼 열어요.
  - 연결은 없지만 이 폰에 예전 기록(`meta`)이 있으면 도쿄 파일로 열어요. 서버 이전부터 쓰던 폰을 보호하려는 거예요.
  - 둘 다 없으면 처음 상태예요.
- 여행에서 빠졌을 때(`tripDrop`): 남은 여행이 없으면 처음 상태예요. 도쿄 파일로 채우지 않아요.
- 앱을 열었는데 서버에 내 여행이 하나도 없고, 이 폰은 어떤 여행에 연결돼 있었다면 처음 상태로 가요. 그 여행에 연결했던 계정(`cloudUser`)이 지금 계정과 같고 로그인이 확인될 때만 기록을 지워요. 아니면 다른 계정으로 로그인한 경우일 수 있으니 기록은 접어만 둬요(검토 후 수정).
- 처음 상태에서 도쿄 여행에 들어오면(초대 등): `tripPlanSync`가 도쿄 파일을 읽어요.

## 빈 화면
- 오늘:
  - 제목 "아직 여행이 없어요", 안내 한 줄.
  - 로그인 전이면 [카카오로 로그인]을 먼저 보여 줘요.
  - [＋ 새 여행 만들기]: 설정 › 여행의 만들기 칸을 열어요. 로그인 전이면 로그인 안내를 해요.
  - [초대 코드 입력].
- 일정, 탐색, 예약, 체크: 한 줄 안내와 [새 여행 만들기].
- 머리글: 제목은 "여행 준비 중", D-day 줄은 비워요.
- 설정의 '이 폰 도쿄 일정으로 만들기'는 처음 상태에서 보이지 않아요.
